# Experiment 6 – Integrate Animations and Transition

**Course:** 24CS2016 – Building Applications using Flutter  
**Name:** Jomi W  
**Register No.:** URK23CS1299

## Aim

To implement animations and page transitions in Flutter.

## Description

This experiment introduces implicit animations in Flutter using the AnimatedContainer widget. A state variable is used to change the width and height of the container when a button is pressed. The AnimatedContainer automatically animates the change in size smoothly over the given duration.

## Source files

- `lib/main.dart`

## How to run

The repository contains the Dart source and `pubspec.yaml`. Generate the platform folders once, then run:

```bash
flutter create .
flutter pub get
flutter run
```

## Result

A Flutter animation application was developed successfully. The AnimatedContainer widget displayed a container with rounded corners and text. Pressing the Animate button changed the size of the container using setState. The size change was animated smoothly, demonstrating Flutter animation behavior.
